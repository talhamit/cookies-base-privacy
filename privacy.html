Cookies Base Scheduler — Privacy Policy

Last updated: October 18, 2026

Overview

Cookies Base Scheduler is a personal tool intended to help its owner organize Pinterest Pin drafts and scheduled publishing.

Information We Handle

The application may store Pin titles, descriptions, image file paths, destination URLs, scheduled times, and account labels entered by the owner. If Pinterest API access is enabled, it may process account information and authorization tokens needed for the integration.

How Information Is Used

Information is intended to be used to manage drafts, schedules, and authorized Pinterest operations. We do not sell personal information or Pinterest data.

Data Security

Credentials and authorization tokens should be stored securely and must never be published in this repository. Actual access controls and security practices should match the deployed application.

Data Retention and Deletion

Locally stored information may be deleted through database maintenance. Information may remain in backups until those backups are deleted.

Third-Party Services

If Pinterest API integration is enabled, Pinterest's terms and privacy practices also apply.

Contact

For privacy questions, contact the application owner through GitHub.

This policy must be updated if the application's actual data collection, hosting, or sharing practices change.
