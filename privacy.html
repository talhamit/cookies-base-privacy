Cookies Base Scheduler - Privacy Policy

Last updated: October 18, 2026

1. Overview

Cookies Base Scheduler is a personal tool intended to help its owner organize Pinterest Pin drafts and scheduled publishing.

2. Information We Handle

The application may store Pin titles, descriptions, image file paths, destination URLs, scheduled times, and account labels entered by the owner. If Pinterest API access is enabled, the application may process account information and authorization tokens needed for the integration.

3. How Information Is Used

Information is used to manage drafts, schedules, and Pinterest operations authorized by the account owner. We do not sell personal information or Pinterest data.

4. Data Security

Credentials and authorization tokens should be protected from unauthorized access and must never be published in a public repository. Actual security practices depend on the deployed application.

5. Data Retention and Deletion

Locally stored information may be deleted through database maintenance. Backup copies may remain until they are deleted.

6. Third-Party Services

If Pinterest API integration is enabled, Pinterest's own terms and privacy practices also apply. Cookies Base Scheduler is not affiliated with or endorsed by Pinterest, Inc.

7. Contact

For privacy questions, contact the application owner through GitHub.

This policy describes the intended use of the application and should be updated if actual data practices change.
